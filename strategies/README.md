# Strategie validate

Qui entrano solo pacchetti che hanno superato la validazione. Ogni pacchetto è una cartella con:

- `code/` — codice della strategia
- `params.json` — parametri congelati
- `preregistration.md` — copia del file di pre-registrazione usato
- `report.md` — resoconto di validazione
- `risk.json` — limiti di rischio della sleeve
- `PROMOTION.md` — stato: candidata, paper, live ridotto, live, con date e ok dell'utente
